Reviewer guidance amendment, 2026-11-12

Both groups receive a brief introduction to all six objective families, two directions, and two decision types before viewing any assigned document. Definitions are copied verbatim from objective-library-v3. The shipped source hash and equality checks identify the canonical source. The introduction is remembered for this reviewer in the current browser; the reference is always available in the sidebar. No quiz or competency examination is required. The taxonomy introduction required no database change. The subsequent comparative simplification below has a versioned SQL migration.

Document review: after reading the document, rate naturalness and realism; then reveal the intended answer sheet and rate semantic fidelity. Objective-family definitions and the meanings of used direction/decision labels appear beside the annotations. Semantic fidelity asks: Does the document reasonably support the listed node/edge meanings and objectives? The response options remain Acceptable / Needs revision / Cannot judge, with a short reason for requested revisions. An implicit but understandable request is acceptable. Reviewers need not enumerate alternatives, construct objective triples, or establish uniqueness. This is a reference-aware support judgment; it is not an independent blind-recovery test or proof that every alternative is excluded.

Comparative review v2 (overall-naturalness-v2): all anonymous versions are shown after the same introduction. Ask one question: Which version reads most naturally as a real document for this situation? Select one version, select multiple versions for a tie, or choose Cannot judge. A comment is optional for every choice. No pairwise comparisons or explanations are required. Judge the overall reading experience for the stated domain/genre/audience; technical vocabulary may be appropriate. Conditions, model identities and previous judgments remain hidden.

If a version is unavailable, it is marked unavailable and cannot be selected. The reviewer can choose among available versions or choose Cannot judge. These cases support preferences among the available versions only; analyse them separately from complete three-version cases. Never interpret an unavailable text as a naturalness loss.

The superseded interface asked two pairwise questions. No comparative responses existed in the live database when this amendment was prepared. The SQL migration refuses to overwrite a workflow with existing comparative responses. Old demo answers stay under their original local storage namespace. New responses store preferences.best as anonymous version labels (an array supporting ties, or ["cannot_judge"]), with optional notes.naturalness. Private exports retain variant order so labels map back to conditions. This is an overall preference measure, not a ranking of all versions or evidence that both downstream stages improve naturalness.

The automated pipeline retains its separate, more systematic alternative checks and blind recovery protocol. Human assessment should be reported as informed by a taxonomy introduction. Existing frozen model protocols, source texts, gold annotations, reviewer allocations and packet snapshots are unchanged. No human ratings were collected by this amendment; all browser test ratings use fixtures and are excluded.
